# ForgePilot Roadmap: v0.1 -> v1.0

- **v0.1 — Guarded local execution ✅** — structured actions, allowlisted commands, independent verification.
- **v0.2 — Autonomous repair ✅** — evidence-driven bounded repair, surgical patches, resume.
- **v0.3 — Repository intelligence ✅** — project detection, relevant context, Git attribution/scope.
- **v0.4 — Test-first engineering ✅** — AUTHOR -> RED -> IMPLEMENT -> GREEN -> REGRESSION -> BUILD.
- **v0.5 — Disposable sandboxes ✅** — Docker/Podman provider, resource limits, PASS-only promotion.
- **v0.6 — Visual verification ✅** — screenshots, frozen baselines, deterministic pixel/region checks, optional local vision.
- **v0.7 — Multi-agent roles ✅** — Planner/Implementer/Debugger/Reviewer/Verifier with enforced separation and structured handoffs.
- **v0.8 — Computer / IDE control ✅** — persistent CDP/replay sessions, accessibility inspection/assertions, click/type/key workflows, screenshots, origin policy, and replayable traces.
- **v0.9 — Product hardening ✅** — environment-backed secrets, explicit approvals, Ed25519 provenance, recovery journals, hardware/model profiles, loopback dashboard, Windows installer, and native Windows UI Automation.
- **v0.10 — One-click/adaptive runtime ✅** — double-click Windows installer/launcher, automatic prerequisite bootstrap, machine inspection, and conservative low-resource model/runtime tuning.
- **v0.11 — Local engineering control center ✅** — repository analysis, natural-language job creation, autonomy presets, explicit capability grants, live job status/logs, cancellation, and signed-result status from the browser UI.
- **v0.12 — Persistent project workspaces ✅** — saved repositories, reusable built-in/custom recipes, a persistent low-resource-friendly FIFO task queue, queued pause/resume, cancellation, auditable retry, and interrupted-run recovery.
- **v0.13 — Workspace intelligence + reversible change safety ✅** — preflight risk analysis, automatic pre-job checkpoints, exact post-run change sets, and conflict-safe rollback that preserves newer human edits.
- **v0.14 — Adaptive runtime health + low-resource model fallback ✅** — per-job resource recheck, health/self-test, installed-model selection, conservative downgrade, and bounded Ollama fallback.
- **v0.15 — Evidence confidence + verified patch review ✅ (this release)** — signed deterministic evidence scoring, conservative dashboard adjustments, privacy-preserving per-file patch metadata, sensitive-path flags, and low-resource-safe review summaries.
- **v1.0 — Verified autonomous software engineering** — integrate these capabilities into a polished end-to-end goal -> evidence-backed artifact workflow with stable task schema, release-quality UX, migration guarantees, and acceptance benchmarks across representative repositories.
