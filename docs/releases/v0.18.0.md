# ForgePilot v0.18.0 — GitHub Release Readiness

v0.18.0 focuses on making ForgePilot a clean, credible open-source repository and a reproducible GitHub release rather than adding another large runtime subsystem.

## Highlights

- Rewritten project landing page with a concise value proposition and one-click quick start.
- GitHub Actions CI on Windows and Linux.
- Tag-driven GitHub Release automation.
- Reproducible `ForgePilot-v0.18.0-windows.zip` package with SHA-256 checksum.
- Release-readiness checker that validates version consistency and repository metadata.
- GitHub issue forms and pull-request template.
- Contributing, security, support, and conduct documentation.
- `.editorconfig` and `.gitattributes` for predictable repository formatting.
- One-click Windows install/run, universal prompt, watchdogs, adaptive low-resource runtime, rollback, and signed provenance remain intact.

## Install

Download `ForgePilot-v0.18.0-windows.zip` from the GitHub Release, extract it, and double-click `INSTALL_FORGEPILOT.cmd`.

## Upgrade

Users of an earlier ForgePilot release can extract v0.18.0 and run `INSTALL_FORGEPILOT.cmd` again. The installer preserves ForgePilot configuration/log/runtime directories while replacing program files.
