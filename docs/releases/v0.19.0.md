# ForgePilot v0.19.0 — Reliability + Finished Deliverables

v0.19.0 focuses on real-world reliability after the GitHub cleanup in v0.18. The normal experience remains one universal prompt and one-click Windows install/run.

## Highlights

- Verified PASS now produces a finished deliverable under `.forgepilot/deliverables/<task>/`.
- Real build artifacts such as `.exe`, `.jar`, `.whl`, and release ZIPs are preferred when present.
- When no standalone build artifact exists, ForgePilot produces a source bundle and adds `RUN.cmd` / `run.sh` when it can identify a Node or Python entry point.
- `forgepilot benchmark --save` measures installed Ollama models locally and can persist the fastest passing recommendation.
- `forgepilot diagnostics` creates a privacy-safe diagnostic ZIP without source code, prompts, secrets, or repository filenames.
- `forgepilot repair` checks installation integrity and runtime health.
- `forgepilot update-check` checks the latest GitHub Release without silently installing anything.
- Dashboard failures now include an actionable diagnosis instead of only a generic FAIL.
- Interrupted dashboard jobs reuse the core `--resume` state when a checkpoint exists.

## Windows install

Download `ForgePilot-v0.19.0-windows.zip`, extract it, and double-click `INSTALL_FORGEPILOT.cmd`. The installer keeps the v0.18 one-click flow and now benchmarks installed local models on a best-effort basis.

## Compatibility

Node.js 22+ remains the required runtime. Existing ForgePilot configuration, runtime, and log directories are preserved by the one-click installer.
