# Support

For normal bugs and feature requests, use GitHub Issues.

Before filing a bug, include:

- ForgePilot version (`forgepilot --version`);
- Windows/OS version;
- output from `forgepilot health`;
- whether Ollama is installed and the model used;
- the last visible progress phase;
- the shortest prompt that reproduces the problem.

Do not post secrets, private source code, access tokens, or exploit details in a public issue. Security-sensitive reports should follow `SECURITY.md`.
